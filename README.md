# Gold Price Calculator

A simple and easy-to-understand gold price calculator project for estimating the value of gold based on karat, weight, and price per gram.

## About

Gold value can vary depending on purity, weight, and the current market price. This project provides a basic reference for understanding how gold value can be estimated for different karats.

## Gold Value Formula

A basic estimate can be calculated using:

```text
Gold Value = Weight × Purity × 24K Gold Price Per Gram
```

For example, 14K gold contains approximately 58.3% pure gold, while 22K gold contains approximately 91.7% pure gold.

## Why Gold Karat Matters

The karat number indicates how much pure gold is contained in an alloy. Higher-karat gold generally contains a greater percentage of pure gold.

Understanding karat purity can be useful when comparing jewelry prices, estimating gold value, or checking the approximate worth of gold by weight.

## Example

Suppose you have a piece of 18K gold. Since 18K gold is approximately 75% pure, its estimated gold content can be calculated using its weight and the current 24K gold price.
